# Plan 0006 — Teknoloji Eğitim Platformu

**Spec:** 0006-tech-education.md | **Status:** Plan ready

## Segments

### Adım 1: Domain (Kurslar, İlerleme, Eğitmenler)
- Entity: `Course` (title, description, level, duration, eğitmen ID)
- Entity: `Enrollment` (öğrenci, kurs, ilerleme %)
- Entity: `Lesson` (kurs içi ders, videoURL, süre)
- Entity: `LessonCompletion` (öğrenci tamamlama)

**Tests:** 8 unit test (Course, Enrollment validators)

### Adım 2: API Endpoints
- `GET /courses` — kurs listesi (filterable: level, eğitmen)
- `POST /enrollments` — kursa kayıt
- `GET /enrollments/{id}` — ilerleme
- `POST /lessons/{id}/complete` — ders işaretle tamamlandı
- `GET /schedule` — bu haftanın dersleri

**Tests:** 10 API test (endpoint validation, auth)

### Adım 3: Persistence
- DbContext: `EducationDbContext` (kurslar, enrollments, lessons)
- Stores: `CourseStore`, `EnrollmentStore`, `LessonStore`
- Migration: `Education_Initial`

**Tests:** 6 integration test

### Adım 4: Web Dashboard
- Component: `CourseCard` (başlık, ikon, ilerleme, seviye)
- Component: `CourseGrid` (responsive grid)
- Component: `ScheduleList` (haftanın dersleri)
- Component: `AnnouncementBand` (duyurular)
- Page: `EducationDashboard` (hepsi bir arada)

**Tests:** 8 component test (a11y, responsive)

### Adım 5: Mobil Dashboard
- Screen: `CoursesScreen` (liste, arama)
- Component: `CourseCard` (mobile optimized)
- Screen: `ScheduleScreen` (haftanın takvimi)

**Tests:** 4 mobile test

### Adım 6: Kapanış
- Dokümanlar: Eğitmen onboarding, öğrenci guide
- Full check
- SHIP

## Öneriler

**R-1:** Kurs seviyesi (`Beginner`, `Intermediate`, `Advanced`) enum olsun — UI filtrede type-safe
**R-2:** İlerleme otomatik %: `completedLessons / totalLessons * 100`
**R-3:** Duyurular ayrı entity, kurs/global filterable
**R-4:** Eğitmen analytics sayfası (opsiyonel 0007'ye defer)
**R-5:** Responsive test fixture: 3 course + 2 enrollment + 5 lesson (seed data)
